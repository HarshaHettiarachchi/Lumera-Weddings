# Lumera Weddings

Lumera Weddings is a photography portfolio and booking website developed using React, TypeScript, and Vite.

The purpose of this project is to provide a simple website where users can view photography work, explore available packages, and make a booking inquiry.

## Features

- Home page with a hero section
- Featured photography gallery
- Photography gallery with category filtering
- Image preview when a gallery image is selected
- Photography packages
- Booking form with validation
- Booking data table
- Contact page with contact information
- Contact form
- Google Map location
- Light and dark theme switching
- Responsive design for different screen sizes

## Technologies Used

- React
- TypeScript
- Vite
- React Router DOM
- Tailwind CSS
- Formik
- Yup
- TanStack Table
- Context API
- Local Storage
- Swiper
- React Icons
